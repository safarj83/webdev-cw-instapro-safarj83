Курсовая работа «Продвинутый JavaScript»: доработка проекта Instapro
📋 Исходная ситуация
За основу взят незавершённый проект предыдущего разработчика (Алёны Юдиной) — аналог Instagram. В проекте уже были реализованы: структура приложения, роутинг между страницами, авторизация/регистрация, компонент загрузки изображений, шапка сайта и вёрстка списка постов.

Что требовалось доделать:

Интегрировать список постов с API

Реализовать страницу добавления поста

Реализовать страницу постов конкретного пользователя

Реализовать функционал лайков

🔧 Выполненные шаги
1. Форк и клонирование репозитория
Создан форк репозитория mielilon/webdev-cw-instapro в личный аккаунт safarj83

Проект склонирован локально, структура изучена:

text

├── api.js            — работа с API
├── index.js          — точка входа и роутинг
├── routes.js         — константы страниц
├── helpers.js        — вспомогательные функции
├── styles.css        — основные стили
├── ui-kit.css        — UI-стили

2. Расширение модуля работы с API (api.js)
Добавлены функции, которых не было у предыдущего разработчика:

getUserPosts({ token, userId }) — получение постов конкретного пользователя

addPost({ token, description, imageUrl }) — создание нового поста

likePost({ token, postId }) — поставить лайк

dislikePost({ token, postId }) — убрать лайк

Каждая функция обрабатывает коды ответов 401 (нет авторизации) и 400 (неверные данные), возвращая данные в удобном формате.

3. Интеграция ленты постов с API (posts-page-component.js)
Удалена статичная вёрстка с захардкоженными постами

Посты теперь рендерятся динамически из массива posts, который загружается с сервера

Добавлены клики по имени автора — переход на страницу постов пользователя

Реализован функционал лайков/дизлайков с проверкой авторизации:

Неавторизованный пользователь получает alert и редирект на страницу входа

Авторизованный — отправляет запрос к API и обновляет данные поста

4. Страница добавления поста (add-post-page-component.js)
Создана форма с полями: загрузка фото и описание

Использован существующий компонент uploadImage для загрузки картинки в облако

Кнопка «Опубликовать» активна только после загрузки изображения

После успешного создания поста — редирект на главную ленту

5. Страница постов пользователя (user-posts.js — новый файл)
Создан новый компонент renderUserPostsPageComponent

Загружает посты конкретного пользователя по userId из API

Обрабатывает случай, когда у пользователя нет постов

Реализованы лайки с перерисовкой страницы

Клик по имени автора внутри этой страницы сохраняет контекст

6. Расширение утилит (helpers.js)
Добавлена функция formatDate(dateString) для форматирования даты в вид «5 минут назад», «3 часа назад», «2 дня назад»

7. Обновление роутинга (index.js)
Добавлена загрузка постов пользователя с показом лоадера

Обработана логика добавления поста с вызовом addPost и редиректом

Реализован корректный переход между страницами с сохранением состояния

🛠 Использованные технологии и подходы
Технология	Применение
Vanilla JavaScript (ES6+)	Вся логика приложения
Fetch API	Работа с REST API
ES-модули (import/export)	Модульная архитектура
Промисы (.then/.catch)	Асинхронные запросы
LocalStorage	Хранение токена авторизации
Компонентный подход	Каждая страница — отдельная функция рендера
Роутинг через состояние	Переключение страниц через goToPage
FormData	Загрузка изображений в облако
